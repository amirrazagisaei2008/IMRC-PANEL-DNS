# IMRC Panel

پنل کانفیگ IMRC روی Cloudflare Workers + D1 با ورود تلگرام.

## تنظیمات لازم (Secrets / Variables)

| نام | کاربرد |
|---|---|
| `BOT_TOKEN` | توکن ربات تلگرام |
| `TG_WEBHOOK_SECRET` | رمز وب‌هوک تلگرام (دلخواه، طولانی) |
| `ADMIN_TG_ID` | Telegram ID ادمین. رسیدها برای این آی‌دی فرستاده می‌شن و ورود ادمین با تلگرام فقط برای این آی‌دی کار می‌کنه |
| `ADMIN_PASSWORD` | رمز پنل مدیریت (روش جایگزین ورود). بعد از ۵ تلاش اشتباه از یک IP، ۱۵ دقیقه قفل می‌شه |

دیتابیس D1 با نام `DB` در `wrangler.jsonc` تعریف شده. جدول‌ها خودکار ساخته می‌شن.

پس از دیپلوی، آدرس وب‌هوک رو از پنل (دکمه‌ی «اتصال ربات») ثبت کن.

## پلن‌ها، رسید و کد تخفیف

- پلن‌ها از پنل مدیریت (بخش تنظیمات) قابل ویرایش‌اند. هر خط: `کلید|نام|روز|قیمت` مثلاً `m|ماهانه|30|150000`.
- کاربر در ربات: `/plans` → انتخاب پلن → (اختیاری) `/code KOD` → عکس رسید.
- ادمین در تلگرام زیر هر رسید دکمه‌ی تأیید پلن (مثلاً «تأیید ماهانه») یا «رد» می‌بینه. تأیید، اشتراک رو خودکار فعال می‌کنه و به کاربر پیام می‌ده.
- کدهای تخفیف از پنل ساخته و مدیریت می‌شن.

## دعوت دوستان

- کاربر با `/invite` لینک اختصاصی می‌گیره.
- وقتی دعوت‌شده برای اولین بار وارد پنل بشه، دعوت‌کننده تعداد روز تنظیم‌شده (پیش‌فرض ۲ روز) اشتراک می‌گیره. هر دعوت فقط یک بار حساب می‌شه.

## توسعه محلی

```
npx wrangler dev
```
